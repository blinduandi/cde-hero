# CDE · 0 → Hero — Pregătire examen

Instrument de pregătire pentru examenul **Circuite și Dispozitive Electronice (CDE)** — UTM, FAF.CDE21.1.

Site static, **fără server, fără internet** (toate fișierele sunt locale). Deschide `index.html` în orice browser.

## Ce conține
- **Teorie** (Tema 1–6): Kirchhoff/Ohm, diode, redresoare, tranzistoare bipolare, amplificatoare, FET.
- **Probleme rezolvate** (27): cu schemă electrică, Se dă / Se cere și rezolvare pas cu pas cu explicații.
- **Antrenament**: probleme cu valori aleatoare + auto-verificare și punctaj.
- **Bilet model**: simulează examenul (3 teorii + 1 problemă).
- **Flashcards**, **Formule esențiale** (cu fracții afișate frumos), **Resurse online**.
- Temă light/dark, responsive pe telefon.

## Structură
```
index.html        — pagina principală
css/style.css     — stiluri
js/theory.js      — teoria (Tema 1–6)
js/problems.js    — problemele rezolvate
js/schematics.js  — schemele electrice (SVG)
js/solvers.js     — generatoarele de antrenament
js/exam.js        — întrebări examen + bilet
js/app.js         — logica aplicației + randare formule
```

Construit din materialele de curs.
